# Build plan: companion panel

Small steps, each leaving `npm test` green and the extension working. Steps 1–6 change no visible behaviour except fixing the skipped-first-prompt gap. Each step ends with a code review (CLAUDE.md workflow).

**Testing conventions.** Tests use `node --test` under `test/`. Anything marked pure or no-vscode in [structure.md](structure.md) is tested directly; VS Code adapters are kept thin and checked by hand in the Extension Development Host (open it through a `.code-workspace` file). Fixtures in `test/fixtures/claude-log/` are synthetic and never copied from real logs.
